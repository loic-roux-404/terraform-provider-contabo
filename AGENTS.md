# AGENTS.md

Terraform provider for [Contabo](https://contabo.com) (VPS, VDS, Object Storage), written in Go with `terraform-plugin-sdk/v2`.

## Build & Test

- `make build` — regenerates the OpenAPI client **and** builds the binary (requires Docker).
- `make build-only` — build only, skipping client regeneration. Prefer this for quick iteration.
- `make test-acc` — runs acceptance tests (`TF_ACC=1 go test -v ./...`). **CAUTION: creates real, billed Contabo resources.** Never run this without the user's explicit request.

## Project Layout

- `main.go` — provider entrypoint (serves `contabo.Provider`).
- `contabo/` — provider package: `provider.go` registers all resources/data sources; `resource_*.go` / `data_source_*.go` per API object; `utils.go`, `handleErrors.go` helpers.
- `client/` — hand-written OAuth2-aware HTTP client (`client.go`, `oauth2.go`); `contabo/oauth2Client/` handles token fetch/cache.
- `openapi/` — **generated** Go client from https://api.contabo.com/api-v1.yaml via `openapi-generator-cli` (see Makefile). Do not hand-edit; regenerate with `make generate-api-clients`.
- `docs/`, `templates/` — registry documentation (Terraform registry format).
- `examples/` — runnable example configurations.

## Conventions

- SDK v2 patterns: resources use `CreateContext`/`ReadContext`/`UpdateContext`/`DeleteContext`, return `diag.Diagnostics`, and set `Importer: schema.ImportStatePassthroughContext`.
- Provider config comes from env vars `CNTB_API`, `CNTB_OAUTH2_TOKEN_URL`, `CNTB_OAUTH2_CLIENT_ID`, `CNTB_OAUTH2_CLIENT_SECRET`, `CNTB_OAUTH2_USER`, `CNTB_OAUTH2_PASS` (see [contabo/provider.go](contabo/provider.go)).
- When adding a new resource: create both `resource_<name>.go` and `data_source_<name>.go`, register both in `ResourcesMap`/`DataSourcesMap` in [contabo/provider.go](contabo/provider.go), and add docs under `docs/resources/` and `docs/data-sources/`.
- API calls go through the generated `contabo.com/openapi` client obtained from the provider-configured `client`; poll long-running operations (see `resource_instance.go` for the pattern with retries/timeouts).

## Pitfalls

- The `openapi/` directory is wiped and regenerated by `make build`; local edits there will be lost.
- Acceptance tests and example `main.tf` can order paid resources — warn the user before `terraform apply` or `make test-acc`.
- `go 1.23`, module path is `contabo.com/terraform-provider-contabo` (not a github.com path).
